网站 SEO 优化怎么做？已上线网站的改造指南

这是我在《独立站 SEO 实战》系列里写的第 13 篇。前面讲的是还没上线的站怎么做，这篇讲已经上线的站怎么改——改不好容易把流量改没了。

先给你结论： 已上线网站做 SEO 的第一铁律是”已经收录的 URL 不要改动”，否则收录和外链都会丢。在此前提下有两招——在老域名子目录下加新页面，以及从 TDK、内链、sitemap、canonical、H 标签五个细节优化老页面。

大原则：已经存在的 URL 不要做任何改动

网站已经上线运营，做 SEO 改造一般都会涉及改版。改版第一条：

已经存在的 URL 不要做任何改动。

为什么？

  1. 已存在的 URL 都被搜索引擎收录了，不能改；
  2. 很多内页已被传播出去，外部有大量外链指向它们，这些外链不能丢，所以不能改。

打个比方：你开了家老店想重新装修，但千万别换门牌号。旧网址已被搜索引擎记住，别的网站也给它做了外链（等于别人给你发了传单）。一换门牌号，之前积累的”人脉”和”知名度”全废。

基于这个大原则，从两方面改造。

第一招：挖需求，加新页面

分析网站的潜在用户群体，他们可能还有哪些需求，针对这些需求做新页面。

  • 新页面可以是小工具，也可以是内容页；
  • 原则：围着潜在用户，尽量满足他们的潜在需求。

这其实等于做一个新网站——只不过不用新域名，而是放在老域名的子目录下。借着老站的名气，开一条新业务线来吸新流量。

第二招：找问题，改老页面

老页面 URL 不能变，但页面本身有很多可优化的空间。

1. 看 TDK 书写是否规范

title 和 description 直接出现在搜索结果里，要好好写：既让搜索引擎抓住重点，又让用户想点进来。

首页：

  • title 结构：”网站名称-Slogan-关键词1-关键词2-关键词3……”
  • description 结构：”网站名是一家提供什么网站，提供关键词1功能、关键词2服务、关键词3内容……”
  • keywords 结构：”网站名,关键词1,关键词2,关键词3……”

目录（分类）首页：

  • title 结构：”子栏目名称-子关键词1-子关键词2-子关键词3……-网站名”
  • description 结构：”子栏目名称是网站名提供的XX服务，主要提供子关键词1功能、子关键词2服务、子关键词3内容……”
  • keywords 可以不写

内页：

  • title 结构：”内页主要功能-子栏目名称-网站名”
  • description 直接写内页内容或功能描述
  • keywords 可以不写

2. 看内链是否合理

正确的内链是树形结构：

  • 网站主页是主干；
  • 子目录是大的枝干；
  • 内页是小纸条；
  • 从首页能一路经过子目录到达内页；
  • 从内页能回到上级子目录，再从子目录回首页。

有些大型站内页太深，从首页点好多下才到，要改进。尽量保证从首页到内页不超过 4 次点击。

3. 看是否有 sitemap

虽然不太可能，但真有的网站没有 sitemap。这时候要建好 sitemap，让爬虫更快把全站页面都收录。

4. 看页面是否设置了 canonical

看页面 head 里有没有 canonical：

为什么要设置：假设你的首页是 https://weixin.qq.com/，被人转发到别的网站，搜索引擎看到的是 https://weixin.qq.com/?from=sitename——它不知道这是新页面还是同一页。

设了 canonical：

不管从哪个带参数的网址进来，搜索引擎都认为是同一页——不会重复收录，也不会认为你造了大量重复页面。

打开任意知名网站（如 App Store 页面）看源码里的 canonical，就能加深理解。

5. 查看 H1、H2、H3 是否合理

  • 一个页面只能有一个 H1；
  • 可以有多个 H2；
  • 每个 H2 下可以有多个 H3。

合理设置 H1/H2/H3 和段落 P，让搜索引擎更容易理解每个网页的重点。

一句话记住

实际改造中肯定有各种细节，上面是核心框架。很多时候，SEO 拼的就是细节——谁愿意花更多时间死磕细节，谁就能拿到更高排名、更多流量。

常见问题（FAQ）

问：改版时旧 URL 一定要保持一致吗？

答：是。已收录的 URL 一旦改动，会导致收录丢失、外链失效，流量断崖式下跌。旧 URL 必须保持不变，新页面加在老域名的子目录下。

问：老页面只能改 TDK 和 H 标签吗？

答：主要是这些细节，另外还有内链结构、sitemap、canonical。核心原则是”URL 不变、页面内容与结构可以优化”。

问：首页到内页最多几次点击合适？

答：建议不超过 4 次。太深，搜索引擎爬取和用户访问都困难，不利于权重传递。
