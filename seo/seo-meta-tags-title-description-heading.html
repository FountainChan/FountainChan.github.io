SEO 元标签详解（上）：Title、Description、Heading

这是我在《独立站 SEO 实战》系列里写的第 9 篇。站内优化一半的功夫，都花在元标签上。这篇先讲最重要的三个：Title、Description、Heading。

先给你结论： Title 是第二大排名因素（占 15%），5060 字符、核心词放首位、带品牌名；Description 不影响排名但影响点击率，150160 字符、自然嵌入关键词；每个页面只能有一个 H1，层级清晰帮搜索引擎理解。

先记住：元标签是站内优化的地基

有些元标签对 SEO 至关重要，其他标签对排名几乎没影响。但要记住第 02 篇说的：SEO 里没有单一最重的东西，很多工作都重要——专注全面的策略，别指望一个标签就让排名起飞。

正确使用元标签，是向搜索引擎传达三件事：

  1. 你的页面关于什么；
  2. 如何阅读这个页面；
  3. 谁应该看到这个页面（即出现在哪些关键词的搜索结果里）。

一、Title（页面标题）

为什么重要

Title 告诉搜索引擎你的网页主要讲什么，是对网页的全面概括。

在排名因素里，标题中的关键词依然占 15%，是优质内容之外的第二大因素。

语义化理解带来的变化

以前，谷歌要求标题严格匹配搜索词；现在谷歌能语义化理解网页，标题不严格匹配也能出现在结果里了。

这意味着：只要你围绕一个词做了高质量页面，标题基于这个词合理编写，就能吃到很多相关词的流量。

简单说：一个高质量页面，能拿到的不只是目标词的流量，还有一堆相关词的流量。

举个例子：下面这四个词意思、需求都类似，谷歌把同一个网站排到了第一名——而这个网站的标题其实只写了其中一个词 “File Type Checker”。

搜索引擎整体评估页面。但标题依然重要——搜索结果里显示的标题直接影响点击率，符合用户需求的标题，点击率更高。

标题最佳实践

  1. 每个页面一个独特标题，简洁准确描述页面内容；
  2. 长度保持在 50~60 字符以内（避免被截断）；
  3. 重要关键词放首位，但要自然，像给访客写的一样；
  4. 标题里带上品牌名称——即使搜索结果不显示，对搜索引擎仍有信号作用。

我的习惯：全站所有页面的标题结尾都加网站名称和域名；网站名称就是域名的话，只加域名就行。

二、Description（页面描述）

为什么重要

描述不是排名因素，但依然重要。

因为大多数时候，描述会跟网址、标题一起显示在搜索结果里：

  • 好的描述提高点击率，吸引用户点你的结果；
  • 描述不能堆关键词，应该是一两个自然的句子，描述页面内容，并把关键词自然带进去；
  • 可以看竞争对手同词的描述怎么写的，参考结构，但别直接复制粘贴。

如果用户搜索的恰好是你网页里的某句话，谷歌可能显示那段匹配文本，而不是你的描述。

描述最佳实践

  1. 每个页面独特的描述，清晰反映页面价值；
  2. 谷歌摘要一般最多 150~160 字符（含空格）；
  3. 包含最重要的关键词，让它们在结果页里被加粗显示——但避免堆砌；
  4. 可选：用一句号召行动（”学习””购买”等）或你的独特卖点。

进阶：还可以用结构化描述让结果更丰富，这属于 Schema Markup，系列第 11 篇会讲。

三、Heading（标题标签 H1~H6）

注意区分

这里的”标题”跟网页标题（Title）不是一个东西，中文都叫”标题”容易混。

为什么 H1 重要

每个网页的 H1 必不可少，要好好写。虽然看下面这张图，H1 并不在排名因素里——那为什么还强调？

因为：

  1. 良好的 H1~H6 帮谷歌梳理网页结构，也就是帮谷歌理解内容；
  2. H1~H6 也是给用户看的，让读者没读完就知道全文讲什么。

所以每个页面都值得在某个位置展示自己的 Heading 大纲（文章目录）。现在只有部分长文有目录，其实每个页面都可以有。

Heading 最佳实践

  1. 标题要和它下面的文本相关——虽然不算排名因素，谷歌还是会考虑；
  2. 让标题反映文本的情绪，别用”第一章…第二章…”这种流水标题；
  3. 别过度堆关键词，保持对用户可读。

Title 和 H1 可以重复吗？

谷歌说：可以一样，也可以不一样。 实在写不出不一样的 H1，就让 H1 和 Title 一样，没问题。

一句话记住

标签 排名作用 长度建议 一句话要点
Title 占排名因素 15% 50~60 字符 独特 + 核心词放首位 + 带品牌
Description 非排名因素，影响点击 150~160 字符 自然句子嵌入关键词，吸引点击
Heading H1~H6 非直接排名因素 — 一个 H1，层级清晰，帮理解
