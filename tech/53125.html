11.2K Star！又一神级 Agent 工作台：让多 Agent 共用同一工作空间

灿烂的番茄2026-09-092026-09-09

你有没有过这样的感觉：明明在用多个 Agent 帮忙干活，效率却总卡在半路？

每次把任务切换给下一个 Agent，都要从头交代一遍项目背景、进行到哪一步；等它吐出结果，再小心翼翼把产出搬回去，接着码下一段。这种断断续续的拉扯感，让原本流畅的协作变成了一场拧巴的独角戏。

今天要介绍的开源项目 holaOS 正是为了解决这个问题而生。

#01 项目介绍

holaOS 是一个开源的 Agent 原生工作台。

简单来说：在 holaOS 里，应用会作为可交互的实时界面和 Agent 并排显示，共享内存、工具和集成。

这意味着：Agent 可以读取你正在使用的应用的真实状态，而你在应用里的操作也会自动成为 Agent 的上下文，无需再手动同步。

#02 项目亮点

#1. 应用是实时界面

传统工具里，应用和 Agent 是分离的：你在 Notion 里做了什么，必须手动告诉 Agent。而 HolaApps 把应用变成 Agent 的实时上下文提供者，省去了来回传递的麻烦。

#2. 共享一份记忆

项目背景、个人偏好、历史记录都存在本地磁盘的普通文件里。换 Agent、关掉会话再打开，记忆依旧保留。而且这些文件可以直接打开进行编辑、删除、修改，数据完全由你掌控。

#3. 多 Agent 协作

多个 Agent 在同一个工作台共存，共享同一套环境，切换 Agent 无需重新配置。

#4. IM 上下文读取

支持 Slack、飞书、钉钉、微信。Agent 可以直接读取你的 IM 频道/群聊，用真实对话作为上下文。每个工具都需单独授权，读取范围明确，没有获得批准前 Agent 不会读取，隐私边界有保障。

#5. 技能（Skills）与 MCP

  • 一键 OAuth 集成：Gmail、Notion、Slack、GitHub、Linear 等 50+ 工具一键接入，所有 Agent 自动继承，无需重复配置。
  • MCP 服务器：支持接入任意 MCP 服务器，扩展 Agent 工具集。
  • 技能（Skills）：把一套工作流打包，任意 Agent 可按需调用。
  • Combos：把技能 + 集成打包成一个”一键安装包”。
