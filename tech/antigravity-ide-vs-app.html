Antigravity IDE 和 App 怎么选？下载前先分清用途

灿烂的番茄2026-10-302026-10-30

搜 Antigravity IDE，打开的教程却在介绍一个管理多个 Agent 的独立应用，这未必是找错了产品。Google 的 Antigravity 入门 Codelab 已经明确区分 Antigravity 独立 App 和 Antigravity IDE：前者管理多个本地 Agent，可以并行安排工作、运行定时任务；后者保留完整代码编辑器，带有 Agent Manager 和 Artifacts。两者都属于 Antigravity，但使用入口和日常工作重心不同。本文按 2026 年 10 月 30 日核对的官方页面解释这种区别，没有安装试用，也不把产品演示写成自己的体验。

#写代码该下载哪一个

我会先看自己一天之中究竟在做什么。需要打开项目、修改文件、查看差异，并在同一个界面里让 Agent 帮忙，IDE 更贴近这种工作习惯。需要给多个任务分别交代目标，再查看各自的进展，独立 App 的管理方式更相关。官方 Codelab 特别说明，2.0 的独立应用可以脱离 IDE 工作；因此，照着旧教程寻找嵌在编辑器里的 Agent Manager，未必能找到新教程的界面。名称相近，不等于操作步骤可以互换。

入口 官方描述的用途 选择时要确认什么
Antigravity IDE 完整的 AI 代码编辑环境，包含 Agent Manager、Artifacts 是否需要直接编辑文件、审阅代码
Antigravity 独立 App 管理多个本地 Agent、并行任务和定时任务 是否以安排和跟踪任务为主
Antigravity CLI 在终端中与 Agent 交互 是否偏好命令行工作方式
Antigravity for IDEs 将 Agent 能力接入已有编辑器的官方扩展 当前编辑器是否在官方支持范围内

这张表只比较入口，不比较模型水平。Codelab 还列出了面向程序集成的 SDK，但普通读者没有必要为了试一个编辑器，先研究整套 SDK。下载从 Antigravity IDE 官方产品页 或 Antigravity 官网 进入，再确认下载项的产品名称与操作系统。产品页当前列出 macOS、Windows、Linux 等平台；具体系统要求和可用版本应以下载时的官方页面为准，不宜沿用几个月前的安装包直链。

#Artifacts 到底用来做什么

官方 IDE 页面列出的能力包括 Tab 补全、自然语言代码命令，以及能跨编辑器、终端和浏览器工作的 Agent。更值得留意的是 Artifacts：它把部分工作结果变成可查看、可反馈的产物，让人从任务层面理解 Agent 的行动，而不必只盯着一长串工具调用。官方还说明，可以在 Artifact 上留下评论，继续引导 Agent。于是，审阅的对象除了代码差异，也包括它对任务的理解与验证结果。

配图来自 Google Antigravity IDE 官方产品页，为官方功能展示，不是本站运行截图。

有了产物，并不等于验收已经完成。一个界面截图能说明页面在某个状态下被打开过，却不能证明所有按钮都能工作；一段测试摘要需要对应实际命令、执行环境和结果。我的建议是把验收条件写得具体一些，例如“修改后运行项目现有测试，列出未通过项；展示桌面和手机宽度下的页面；不得替我提交或部署”。这些是使用者给任务加的约束，不能反过来当成 Antigravity 默认保证的行为。

#第一次使用别从主项目开始

官方 Codelab 的准备条件包括本地安装、Chrome 浏览器和个人 Gmail 账户，文中主要讲独立 App，并不覆盖 CLI 与 SDK 的全部操作。读教程时先辨认它在讲哪一个入口，再核对当前产品的账户和地区要求，能少走一些弯路。官方材料说明 Agent 可以操作终端和浏览器，我因此更愿意先给它一个不含密钥的样例项目，让它解释目录、提出修改建议，再开放写文件。能用自然语言派任务，不意味着操作系统权限和网站登录状态就不重要了。

首次试用可以选一个很小的任务，例如给样例页面补充空状态。开始前保存项目基线，限制可修改目录，明确哪些命令需要确认；完成后看文件差异、测试输出和页面状态，而不只看聊天框里的“完成”。涉及生产数据库、付款、发布、删除或真实客户资料时，应该另设人工审批，且实际检查软件提供的权限设置。提示词是一层约束，不能代替权限隔离。

先验证，再扩大授权。

这也与本站的 DeepSeek Harness 入门 有相通之处：Agent 能做多少事，取决于模型之外的工具、工作区和权限。如果关注的是编程订阅费用，可以接着看 OpenCode Go 的适用范围，但订阅方案和 IDE 是不同层面的选择，不能仅用月费判断整套工作环境是否合适。

#常见疑问

Antigravity App 就是 IDE 的新名字吗？ 当前官方 Codelab 把它们列为不同入口，独立 App 不依赖 IDE，原有 IDE 仍然提供。已经有编辑器是否必须换？ 官方还提供 IDE 扩展路线，先检查支持列表与功能差异即可；本文没有验证扩展和完整 IDE 的功能是否完全一致。免费额度和模型列表是什么？ 这些会影响使用，但本文核对的范围是产品形态，不给未经当日账户核验的额度承诺。

我认为这类工具最容易造成的误会，是把“换一个入口”想成“换来一种能力保证”。IDE 适合近距离编辑和审阅，App 更强调管理任务；无论选哪一个，最终都要回到实际改动和验证记录。下载项选对了，工作才刚开始。

资料：Antigravity IDE 产品页 · Google 官方入门 Codelab。核对日期：2026-10-30。
